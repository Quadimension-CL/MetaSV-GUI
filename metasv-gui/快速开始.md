## 📋 功能使用指南

### 1. 数据集采集

**步骤：**
1. 点击"📦 数据集采集"标签
2. 填写以下路径：
   - 基础声库：选择 `.nofs` 文件
   - 教师声库：选择 `.nofs` 文件
   - 训练项目：选择 `.svp` 文件
   - 验证项目：选择 `.svp` 文件
   - 词典目录：选择 `clf-data` 目录
   - 输出目录：指定数据集保存位置
3. 选择语言（普通话/日语）
4. 点击"开始采集"
5. 查看实时日志

**输出：**
- `dataset/base_model.dnni`
- `dataset/dataset.json`
- `dataset/*.npz`

### 2. 模型训练

**步骤：**
1. 点击"🎓 模型训练"标签
2. 填写：
   - 基础模型：`dataset/base_model.dnni`
   - 数据集：`dataset/dataset.json`
   - 输出目录：`runs/demo`
   - 训练步数：6000（默认）
   - 时间限制：1800 秒（可选）
3. 点击"开始训练"
4. 实时监控训练日志

**提示：**
- 训练可能需要较长时间
- 可以随时点击"停止"中断
- 训练日志每秒自动更新

**输出：**
- `runs/demo/trained-base.dnni` - 训练后的模型
- `runs/demo/latest.pt` - 检查点
- `runs/demo/report.json` - 训练报告

### 3. 声库导出

**步骤：**
1. 点击"📤 声库导出"标签
2. 填写：
   - 基础声库：原始 `.nofs` 文件
   - 训练模型：`runs/demo/trained-base.dnni`
   - 输出文件：`trained.nofs`
3. 点击"导出声库"

**输出：**
- 可在 OpenSV 或 MetaSV 中使用的 `.nofs` 声库文件

### 4. 歌声渲染

**步骤：**
1. 点击"🎤 歌声渲染"标签
2. 填写：
   - 声库：`.nofs` 文件
   - 项目：`.svp` 文件
   - 词典目录：`clf-data` 目录
   - 输出文件：`.wav` 文件路径
   - 语言：普通话/日语
   - 音高模式：音符音高/自动 F0
3. 点击"开始渲染"

**输出：**
- 单声道 WAV 音频文件

## 🔧 故障排除

### 问题：端口被占用
**症状：** `Address already in use` 或 `Port 5001 is in use`

**解决方案：**
1. 修改 `web_gui.py` 中的端口号
2. 将 `port=5001` 改为其他端口（如 `5002`）
3. 重新启动

### 问题：无法找到 MetaSV
**症状：** 页面显示"未找到 MetaSV 可执行文件"

**解决方案：**
1. 确保 MetaSV 已编译：
   ```bash
   cd /Volumes/Astra/SV/model/MetaSV-main
   source ~/.cargo/env
   cargo build --release
   ```
2. 检查路径：`target/release/metasv` 是否存在

### 问题：训练环境错误
**症状：** 采集或训练时报错

**解决方案：**
```bash
cd /Volumes/Astra/SV/model/MetaSV-main
UV_LINK_MODE=copy uv sync --project training --locked
```

### 问题：浏览器无法访问
**症状：** 浏览器显示"无法连接"

**解决方案：**
1. 检查服务器是否运行：
   ```bash
   ps aux | grep web_gui
   ```
2. 检查防火墙设置
3. 尝试使用 `http://127.0.0.1:5001`
