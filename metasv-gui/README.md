# MetaSV GUI - 图形界面应用

MetaSV 的原生桌面图形界面，基于 Python + PyQt6 开发。

## 功能特性

- ✅ **数据集采集** - 可视化配置采集参数，实时查看采集日志
- ✅ **模型训练** - 设置训练参数，监控训练进度
- ✅ **声库导出** - 一键导出训练完成的声库
- ✅ **歌声渲染** - 使用声库渲染 SVP 项目

## 安装

### 方式一：使用启动脚本（推荐）

```bash
cd /Volumes/Astra/SV/model/MetaSV-main/metasv-gui
chmod +x run.sh
./run.sh
```

启动脚本会自动：
1. 创建 Python 虚拟环境
2. 安装所需依赖
3. 启动图形界面

### 方式二：手动安装

```bash
cd /Volumes/Astra/SV/model/MetaSV-main/metasv-gui

# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 启动 GUI
python3 metasv_gui.py
```

## 使用说明

### 1. 数据集采集

**步骤**：
1. 选择基础声库（.nofs 文件）
2. 选择教师声库（.nofs 文件）
3. 选择训练项目（.svp 文件）
4. 选择验证项目（.svp 文件）
5. 选择词典目录（clf-data 目录）
6. 选择语言（普通话/日语）
7. 选择输出目录
8. 点击"开始采集"

**输出**：
- `dataset/base_model.dnni` - 基础模型
- `dataset/dataset.json` - 数据集索引
- `dataset/*.npz` - 特征文件

### 2. 模型训练

**步骤**：
1. 选择基础模型（`dataset/base_model.dnni`）
2. 选择数据集（`dataset/dataset.json`）
3. 选择输出目录
4. 设置训练步数（默认 6000）
5. 设置时间限制（默认 1800 秒，0 表示无限制）
6. 点击"开始训练"

**输出**：
- `runs/demo/trained-base.dnni` - 训练后的模型
- `runs/demo/latest.pt` - 最新检查点
- `runs/demo/report.json` - 训练报告

**提示**：
- 训练可能需要很长时间，建议使用 GPU
- 可以点击"停止"按钮中断训练
- 使用 `--resume` 参数可以续训（需要修改代码）

### 3. 声库导出

**步骤**：
1. 选择基础声库（原始 .nofs 文件）
2. 选择训练模型（`runs/demo/trained-base.dnni`）
3. 选择输出文件名（.nofs）
4. 点击"导出声库"

**输出**：
- `trained.nofs` - 可以在 OpenSV 或 MetaSV 中使用的声库文件

### 4. 歌声渲染

**步骤**：
1. 选择声库（.nofs 文件）
2. 选择 SVP 项目文件
3. 选择词典目录（clf-data）
4. 选择输出音频文件（.wav）
5. 选择语言和音高模式
6. 点击"开始渲染"

**音高模式**：
- `notes` - 使用音符音高（当前支持）
- `auto` - 自动 F0 预测（未来支持）

## 技术架构

- **前端**: PyQt6 (原生桌面组件)
- **后端**: Python 子进程调用 MetaSV 命令行工具
- **线程**: QThread 实现非阻塞后台处理
- **日志**: 实时显示命令输出

## 系统要求

- **Python**: 3.10+
- **操作系统**: macOS (也支持 Linux/Windows)
- **依赖**: PyQt6

## 故障排除

### 问题：无法找到 MetaSV 可执行文件

**解决方案**：
- 确保 MetaSV 已编译：`cargo build --release`
- 可执行文件位于：`../target/release/metasv`
- 首次启动时会提示手动选择

### 问题：训练环境错误

**解决方案**：
```bash
cd /Volumes/Astra/SV/model/MetaSV-main
UV_LINK_MODE=copy uv sync --project training --locked
```

### 问题：词典目录不正确

**解决方案**：
- clf-data 目录应包含语言对应的词典文件
- 普通话：需要包含拼音到音素的映射
- 日语：需要包含假名到音素的映射

## 高级功能

### 自定义训练参数

如需更多训练参数（学习率、批量大小等），可以直接编辑 `metasv_gui.py` 中的命令构建部分。

### 批量处理

目前 GUI 不支持批量处理，如需批量操作请使用命令行版本。
