# MetaSV GUI - 跨平台总结

## ✅ 完成状态

MetaSV 图形界面已完成开发，**完全支持 Windows、macOS 和 Linux**！

## 📦 项目结构

```
MetaSV-main/
├── target/
│   └── release/
│       ├── metasv          # macOS/Linux 可执行文件
│       └── metasv.exe      # Windows 可执行文件
├── training/               # Python 训练环境
└── metasv-gui/            # 图形界面
    ├── web_gui.py         # Web 服务器（Flask）
    ├── metasv_gui.py      # 桌面应用（PyQt6）
    ├── templates/
    │   └── index.html     # Web 界面前端
    ├── start_web.sh       # macOS/Linux 启动脚本
    ├── start_web.bat      # Windows 启动脚本
    ├── run.sh             # macOS/Linux 桌面版
    ├── run.bat            # Windows 桌面版
    ├── 启动MetaSV.py      # Python 启动脚本
    ├── requirements.txt   # Python 依赖
    ├── README.md          # 完整文档
    ├── 快速开始.md        # 快速指南
    └── Windows使用指南.md # Windows 专用文档
```

## 🌐 两个版本

### 1. Web GUI（推荐）✅

**优点：**
- ✅ 轻量级，启动快速
- ✅ 跨平台完全支持
- ✅ 现代化界面设计
- ✅ 可以远程访问
- ✅ 无需复杂依赖

**启动方式：**

**macOS/Linux:**
```bash
cd metasv-gui
./start_web.sh
# 或
source venv/bin/activate && python3 web_gui.py
```

**Windows:**
```powershell
cd metasv-gui
.\start_web.bat
# 或
.\venv\Scripts\activate.ps1
python web_gui.py
```

**访问地址：** http://localhost:5001

### 2. PyQt6 桌面 GUI

**优点：**
- ✅ 原生桌面体验
- ✅ 文件对话框选择
- ✅ 更像传统应用

**启动方式：**

**macOS/Linux:**
```bash
cd metasv-gui
./run.sh
# 或
python3 启动MetaSV.py
```

**Windows:**
```powershell
cd metasv-gui
.\run.bat
```

## 🎨 功能特性

所有版本都包含完整的 4 大功能：

### 1. 📦 数据集采集
- 配置基础声库和教师声库
- 设置训练和验证项目
- 选择语言和词典
- 实时日志输出

### 2. 🎓 模型训练
- 加载数据集和基础模型
- 配置训练步数和时间限制
- 后台训练，可随时停止
- 监控训练进度

### 3. 📤 声库导出
- 选择训练完成的模型
- 导出为 .nofs 格式
- 一键操作

### 4. 🎤 歌声渲染
- 使用声库渲染 SVP 项目
- 支持普通话和日语
- 音符音高或自动 F0
- 输出单声道 WAV

## 🚀 快速开始

### macOS（当前测试通过）

```bash
# 1. 启动 Web GUI
cd /Volumes/Astra/SV/model/MetaSV-main/metasv-gui
./start_web.sh

# 2. 打开浏览器
# http://localhost:5001
```

### Windows

```powershell
# 1. 进入项目目录
cd C:\Users\你的用户名\Documents\MetaSV-main\metasv-gui

# 2. 双击 start_web.bat 或运行：
.\start_web.bat

# 3. 浏览器会自动打开或手动访问
# http://localhost:5001
```

### Linux

```bash
# 1. 启动 Web GUI
cd ~/MetaSV-main/metasv-gui
./start_web.sh

# 2. 打开浏览器
# http://localhost:5001
```

## 🔧 依赖安装

### 所有平台通用

**Python 依赖：**
```bash
pip install Flask          # Web GUI
pip install PyQt6          # 桌面 GUI（可选）
```

**MetaSV 依赖：**
- Python 3.10+
- Rust (cargo)
- CMake
- UV 包管理器

## 💡 使用建议

### 推荐方案

1. **初学者** → Web GUI
   - 安装简单
   - 界面直观
   - 跨平台一致

2. **高级用户** → 命令行 + Web GUI
   - 命令行用于批量处理
   - Web GUI 用于单次任务和监控

3. **开发者** → 命令行
   - 完整功能
   - 脚本自动化
   - 最大灵活性
